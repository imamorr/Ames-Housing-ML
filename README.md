# Ames housing price prediction project

## Данные
В качестве данных из открытого источника был взят исходный датасет Ames Housing на 2930 записей о домах, каждая из которых имеет 79 признаков. Источник: https://www.kaggle.com/datasets/shashanknecrothapa/ames-housing-dataset

## Цели
1. Исследовать исходный датасет: понять распределение целевой переменной, проверить признаки на предмет выбросов, выявить коллинеарные признаки, изучить пропуски
2. Провести препроцессинг данных для обучения моделей
3. Обучить модели на тренировочной выборке и подобрать гиперпараметры с помощью кросс-валидации
4. Выбрать лучшую и провести оценку на отложенной тестовой выборке
5. Сделать анализ ошибок модели и с его помощью улучшить модель

## Использованные инстументы
Python, pandas, matplotlib, seaborn, scipy, numpy, jupyter notebook, scikit-learn

## Анализ исходного датасета

### Анализ числовых признаков на выбросы
Целевая переменная saleprice имеет тяжелый хвост справа, выбросов не обнаружено, при обучении в качестве метрик оценки будут взяты MAE, r-squared.
Признак lot_area имеет тяжелый хвост справа. Среднее больше медианы в ~10,5 раз. При анализе признака на предмет выбросов по правилу 3 IQR было обнаружено 53 выброса, не было выявлено очевидных деталей, по которым их можно было бы принять за действительные выбросы и удалить. При обучении линейной модели выбросы могут быть удалены или логарифмированы.

### Анализ корреляций
Обнаружено 4 признака, которые коррелируют с четырьмя другими более чем на 79%, потенциальна мультиколлинеарность. Оснований для удаления признаков недостаточно. Можно будет обучить модели без этих признаков для проверки гипотезы.

### Анализ пропусков
Пропуски в числовых признаках заполнены медианой ряда.
В категориальных признаках есть пропуски как отсутствие объекта и как отсутствие записи. Заменены на категорию 'Missing'. Разделение на 'None' и 'Missing' показало худшие результаты.

## Обучение моделей
Обучение ridge-model и подбор оптимального alpha производилось посредством cross-validate. Применено 1-SE rule для поиска наиболшего возможного alpha.
Линейная модель показала себя заметно хуже по сравнению с ridge. Аномальные значения признака lot_area, потенциальная мультиколлинеарность в данных — одни из возможных причин....????
