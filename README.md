# Ames housing ml project

## О проекте
Проект разрабатывается с целью получения практического опыта в сфере машинного обучения в реальных условиях, где данные имеют свои недостатки, датасет нуждается в подробном изучении и не может быть сразу использован для обучения моделей.

## Данные
В качестве данных из открытого источника был взят исходный датасет Ames Housing на 2930 записей о домах, каждая из которых имеет 79 признаков. Источник: https://www.kaggle.com/datasets/shashanknecrothapa/ames-housing-dataset

## Цели
1. Исследовать исходный датасет: понять распределение целевой переменной, проверить признаки на предмет выбросов, выявить коллинеарные признаки, изучить пропуски
2. Провести препроцессинг данных для обучения моделей
3. Обучить модели на тренировочной выборке, сравнить их оценки метрик по предиктам на тестовой и выбрать лучшую
4. Сделать анализ ошибок модели и с его помощью улучшить модель

## Использованные инстументы
Python, pandas, matplotlib, seaborn, scipy, numpy, jupyter notebook

## Анализ исходного датасета

### Анализ числовых признаков на выбросы
Целевая переменная - saleprice, распределена ненормально, имеет очень тяжелые хвосты, но очевидных выбросов не обнаружено
При анализе числовых признаков обнаружено странное распределение признака lot_price. Среднее больше медианы в ~10,5 раз. При анализе признака на предмет выбросов по правилу 3 IQR было обнарудено 53 выброса, однако при дополнительной проверке не было выявлено очевидных деталей, по которым их можно было бы принять за действительные выбросы и удалить. При обучении моделей их работа с этим признаком будет дополнительно проверена, если потребуется, выбросы будут удалены, либо признак будет логарифмически преобразован.

### Анализ корреляций
В исходном датасете обнаружено 4 признака, которые коррелируют с четырьмя другими более чем на 79%. Это может помешать линейной модели подобрать параметры из-за мультиколлинеарности, но пока что я не буду удалять эти признаки, потому что оснований для этого недостаточно. В дальнейшем модели можно будет обучить на датасете с этими и без этих признаков, по оценке метрик определить, какой вариант обучает модели лучше.

### Анализ пропусков
В числовых признаках практически нет пропусков, только в признаке lot_frontage пропусков значительное количество - 16,7%, в препроцессинге заполню значения через SimpleImputer со стратегией 'median' дабы сохранить данные, а не удалить из-за отсутствия записи в каком то признаке.
В категориальных признаках пропусков много, но анализ показал, что большинство из них — не пропуски а отсутствие объекта, например, бассейна. Также среди них есть признаки с реальными пропусками, но их количестыво не превышает 6%. Их так же заменю на категорию 'Missing' через SimpleImputer. Это позволит не потерять потенциально нужные данные для обучения и научит модель справляться с такого рода пропусками.
